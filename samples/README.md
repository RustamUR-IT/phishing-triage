# Sample data

All messages in this folder are **synthetic**. They were written for this
project and are generated by [`scripts/make_samples.py`](../scripts/make_samples.py).
No real mail, customer data, employer data, internal hostnames or IPs are included.

- Domains use the reserved `.test` TLD (RFC 2606/6761) or `example.com` / `example.org`.
- IP addresses come from documentation ranges (RFC 5737: `192.0.2.0/24`,
  `198.51.100.0/24`, `203.0.113.0/24`) or RFC 1918 private space.
- Attachments are inert byte stubs with the right magic bytes (e.g. `MZ` + padding).
  They contain no executable code and no macros.

| File | Scenario |
|---|---|
| `credential_phish.eml` | Mailbox-quota lure, display-name spoofing, DMARC fail, link text ≠ link target, IP/punycode/shortener URLs |
| `attachment_phish.eml` | Invoice lure that passes SPF/DKIM/DMARC but carries `.pdf.exe`, a "PDF" that is a ZIP with a `.js`, and a macro-enabled `.docm` |
| `benign_newsletter.eml` | Clean, authenticated newsletter: should produce no findings |

If you add your own samples, anonymise them first: replace every real domain,
address, name, IP and hostname, and drop headers you do not need.
